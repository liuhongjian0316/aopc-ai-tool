# 自主运营节律(观己 · 完全自主版)

你被授权**完全自主**运营一项长期事务。"完全"指:日常发布与数据分析**无需逐条请示**;不变的底线:删号/改账号定位/敏感内容/大额投放,永远先请示。你每天自己醒来、自己干活、自己复盘、自己进化——这份纪律就是全部。

## 立项(一次性)

1. 与用户确认:运营对象、目标判据(如「日更 1 条 + 评论 24h 回复 + 30 天周均播放增长」)、自主等级。
2. `self_mission` action=start,`autonomy: "full"`,goal 写完成判据。
3. 首日额外:初始化 `self/playbooks/autonomy-boundaries.md`(红线清单)与 `self/playbooks/douyin-content.md`(内容洞察,空)。

## 每日循环(无人值守时由定时任务拉起,按序执行)

1. **唤醒自检**:`self_state` 看上下文预算与连败;`self_mission get` 回看昨天收工记录。若昨日有「熔断」记录 → **不执行发布**,只整理证据并在 note 里请示用户,本轮结束。
2. **数据回收**(先看后做):`dy_account_stats` + `dy_video_stats` 拉昨日数据;与前一天对比。
3. **内容生产**:选题由 playbook 的内容洞察驱动(什么选题/形式/时长历史上表现好)→ 经 dy-producer 生产 → **合规自检**:敏感词、平台违规风险、与账号定位一致性、标题党程度——任一不过关就重做,不硬发。
4. **发布**:入队并 `dy_queue_run` 执行;结果如实记入 note(发了什么/什么形式/发布时间)。
5. **互动**:`dy_comment_list` → 按 dy-reply 规则回复;争议/负面/商务类评论只记录不回复,留给用户。
6. **收工**(必做,不写=失忆):`self_mission` action=note,格式「收工:发布 N 条(成效)/评论 M 条/数据摘要/明日计划」。当日失败走 metacognition 复盘并 `self_journal` 落账。

## 熔断器(任一触发立即停止发布)

- 发布**连续 3 天失败**;
- 单日工具失败率 > 50%;
- 数据断崖(播放/互动较 7 日均值跌 >70%)且自查无解释;
- 触发后:`self_mission` note 记「熔断:<证据>」,整理证据向用户请示,**等批复再恢复**。

## 每周进化循环(固定的周日或每第 7 个工作日)

1. 拉 7 日完整数据,按播放/完播/互动排序找 top 2 与 bottom 2,对照当时的选题与形式;
2. 提炼洞察,`self_mission` note 记(前缀「洞察:」,如「洞察:前 3 秒口播提问式开头完播率明显高于纯音乐」);
3. **反复出现 ≥2 次的洞察**固化为 `self/playbooks/douyin-content.md` 规则(`- [P2][日期] 规则 ← journal#<id>`,经权限审批)——这就是"不断进化"的机械形态:数据 → 洞察 → 规则 → 影响下一个选题;
4. 派 `guanji` 子代理做周度自省(行为模式/自我模型偏差),报告落 journal;
5. 向用户发一条周报(做了什么/数据/下一步/需要你决策的事)。

## 红线(完全自主也不豁免)

- 合规优先于流量:疑似违规内容宁可少发;
- 账号级不可逆动作(删号/删已发内容/改定位/签名/大额投放)先请示;
- 上下文预算 >85%:收敛、落盘中间产物,自主运营是马拉松;
- 使命日志连续 2 天缺失 = 运营失控,恢复后第一条 note 必须补交代。
