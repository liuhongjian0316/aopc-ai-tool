# 抖音数据分析

## 流程

1. **拉数**：依次调用 douyin-pilot 的 MCP 工具
   - `dy_account_stats`（账号概况，dateRange 用 7d/30d）
   - `dy_video_list`（拿最近作品的 item_id）
   - `dy_video_stats`（每个作品的播放/点赞/评论/完播）
   - `dy_snapshot`（顺手保存当日快照，供后续趋势对比）
2. **分析**（对返回 JSON 做计算，不用猜数）：
   - 均值对比：每条作品的播放 vs 账号近 7 日平均，标出超均值 1.5 倍的「爆款候选」和低于 0.3 倍的「拖后腿作品」
   - 互动率 = (点赞+评论+收藏)/播放，完播率单独看
   - 话题/标题模式归纳：爆款候选的标题结构、发布时段、时长有什么共性
3. **输出报告**（中文，结构如下）：
   - **今日概览**：粉丝、播放、互动的绝对数与环比（有历史快照时读 `${AOPC_PLUGIN_DATA}/douyin-pilot/snapshots.json`）
   - **作品表现**：列表，爆款/拖后腿标注
   - **结论**：最多 3 条，每条必须给可执行动作（例：「完播率低于 20% → 下一批视频压到 25 秒内」）
4. **回写队列**：结论若涉及发布调整，写入待办让用户确认，或直接用 `dy_queue_add` 排进发布日历（先问用户）。

## 注意

- 数据接口返回空/报错时如实说明，不要编造数字。
- 没有授权账号时引导先走 `dy_config_set` + `dy_auth_listen` 授权流程。
