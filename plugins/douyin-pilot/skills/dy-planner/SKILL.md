# 抖音选题与排期

## 流程

1. **定位确认**（首次必问，之后记住）：账号定位、目标人群、更新频率（建议新号日更或隔日更）、内容形式（口播/图文/AI 生成）。
2. **数据输入**：
   - 调 `dy_account_stats` + `dy_video_list` 看现有表现（已有爆款优先复制其模式）
   - 竞品/热点数据：本插件暂无对标 API，让用户粘贴对标账号近期爆款，或用 WebSearch 搜相关热点话题
3. **选题产出**：一次给 7~14 个选题，每个包含：
   - 选题名 + 一句话钩子（前 3 秒留人的点）
   - 形式与预估时长
   - 话题标签建议（`#xx#`，蹭大流量话题但必须相关，违和话题会被降权）
   - 预期发布时段（流量高峰：11-13 点 / 18-22 点，新号避开整点扎堆）
4. **生成内容日历**：表格输出（日期/选题/形式/标签/时段），经用户确认后用 `dy_queue_add` 逐条排入发布队列（视频文件可先留占位，由 dy-producer 技能补齐）。

## 原则

- 选题要能系列化：单点爆款不如可批量生产的模板。
- 每周复盘（配合 dy-analytics）滚动替换掉 30% 效果差的选题方向。
- 不碰平台违禁方向（医疗夸大、金融承诺、引导站外交易等）。
