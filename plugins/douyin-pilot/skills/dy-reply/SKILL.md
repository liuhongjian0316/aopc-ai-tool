# 抖音评论/私信客服

## 评论回复流程

1. 拉评论：`dy_comment_list`（itemId 从 `dy_video_list` 拿）
2. 逐条分类：**咨询**（产品/价格/怎么买）、**正面**（夸赞/支持）、**负面**（吐槽/质疑）、**骚扰引流**（广告/加V）、**可置顶**（有价值的提问）
3. 处置：
   - 咨询 → 按知识库回复（知识库不存在时先向用户要：产品卖点、价格、常见问题清单）
   - 正面 → 个性化短回复，禁止模板味重的「感谢支持」连发
   - 负面 → 先给用户看草稿，确认后再发（负面回复公开可见，风险最高）
   - 骚扰引流 → 不回复，汇总给用户
4. 发送：`dy_comment_reply`（工具自带敏感词拦截；命中拦截的说明已规避了平台导流风险）

## 私信（当前阶段说明）

- 已认证**企业号**：等 webhook 通道开通（Phase 2），接通前手动模式。
- 普通账号：`dy_dm_rules` 设置关键词规则（如「价格」→ 话术），Phase 2 通道接入后自动生效。
- 私信自动回复必须声明 AI 身份（如「我是 AI 助手，复杂问题会转人工」），这是平台规则趋势，也降低投诉率。

## 红线（所有自动回复通用）

- 绝不出现站外导流词（微信/vx/扫码/链接）、绝不承诺收益/疗效、绝不辱骂对线。
- 同一账号每小时自动回复 ≤30 条，超出的攒批给用户确认后发。
- 拿不准的一律转人工：整理成「待处理清单」交用户，不硬编。
